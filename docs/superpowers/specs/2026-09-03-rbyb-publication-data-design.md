# Rb–Yb Publication Data Repository Design

## Purpose

Create a private, publication-focused repository containing the numerical data and simulation code that support the paper *Optically accessible 87Rb–171Yb Rydberg interactions and a Förster CZ gate*. The repository must let a reader trace each quantitative paper result to a machine-readable record and reproduce it without exposing unrelated exploratory work.

The package will not include figure-generation code or rendered figures. Figure 2 is a schematic and has no numerical source data.

## Scientific scope

### Förster channel

Publish:

- the fixed-m distance, magnetic-field, and angular characterization behind Figure 1;
- the bright-eigenstate composition and channel constants behind Figure 1;
- the all-magnetic-sublevel composite-revival CZ calculation behind Figure 3 and Table I;
- the pulse command, finite-response calculation, bounded-position and Rabi-scale samples, magnetic-field scan, nominal population trajectories, assumptions, and convergence metadata.

The Förster gate is the paper's only gate construction.

### Van der Waals channel

Publish:

- the dense all-magnetic-sublevel pair track, zero-field C6 calculation, magnetic-sector values, and magnetic-field scan behind Figure 4;
- the database and solver provenance needed to reproduce those values;
- the reduced two-level sequential-pulse feasibility estimate reported only in Appendix A and Table III.

The documentation and filenames must not describe the van der Waals calculation as a gate design or assign it a process fidelity. It is a reduced feasibility estimate, not a driven multichannel simulation and not a second principal CZ result.

### Curated comparison table

Publish Table II as a small machine-readable literature-comparison CSV, including citations and explicit `not reported` values. This table is curated source data, not simulation output.

### Exclusions

- exploratory channel searches and superseded candidate scans;
- obsolete square-pulse and earlier optimization workflows;
- plotting scripts, rendered figures, and LaTeX manuscript sources;
- PairInteraction database binaries, which are large third-party assets;
- caches, virtual environments, logs, and generated bytecode.

## Code boundaries and data flow

`forster_model.py` will own the shared PairInteraction state selectors, basis construction, lifetime lookup, pair-Hamiltonian projection, and fidelity helpers. The two Förster entry points will use it to generate characterization data and the final composite-gate record respectively. Plotting-only imports and output paths will be removed.

`reproduce_vdw_dense.py` will generate the expensive PairInteraction pair data. `reproduce_vdw_feasibility.py` will consume that stored dense data and generate the inexpensive Appendix A feasibility record and R6-deviation CSV.

```text
PairInteraction databases
        │
        ├──▶ Förster characterization ──▶ data/forster_characterization.json
        │
        ├──▶ Förster composite CZ ──────▶ data/forster_gate_results.json
        │
        └──▶ vdW dense pair track ──────▶ data/vdw_dense_data.json
                                               │
                                               ▼
                                    reduced feasibility estimate
                                               │
                                               ├──▶ data/vdw_feasibility_results.json
                                               └──▶ data/vdw_r6_deviation.csv
```

## Reproducibility and provenance

- Use `uv` with an exact lockfile.
- Pin PairInteraction 2.5.0 and compatible Python, NumPy, and SciPy versions.
- Record Rb v1.2 and Yb171 MQDT v1.4 database file sizes and SHA-256 hashes without redistributing the database files.
- Make paths repository-relative.
- Store units and model assumptions explicitly in each output.
- Document which commands are quick and which require large sparse diagonalizations.
- Preserve the manuscript's distinction between calculated values, model assumptions, and unmeasured experimental quantities.

## Verification

Automated checks will compare stored data against the manuscript's headline values, including:

- Förster defect: −0.763732 MHz;
- full pair splitting at 3.4 µm: 30.8 MHz;
- first-maximum transfer: 99.69%, with 0.287% spectator leakage;
- composite-gate nominal average fidelity: 99.9314%;
- sampled joint minimum: 99.8650%;
- total gate duration: 360.028949 ns;
- van der Waals C6/h: +73.579 GHz·µm⁶;
- van der Waals working point: U/h = 57.072 MHz and bare-product weight 0.969718 at 3.3 µm;
- Appendix A reduced estimate: Favg = 0.997699 in the (+1/2,+1/2) sector and 0.997696 as the worst of four sectors.

The inexpensive van der Waals feasibility script will be rerun and its generated outputs compared with the committed records. The expensive PairInteraction calculations will receive targeted smoke checks plus schema and headline-value validation; full reruns will be attempted where local resources permit.
